# warpnull

Warp and reshape null text streams with deterministic transforms.

**Site:** https://theworker02.github.io/warpnull/

## Install / run

```bash
git clone https://github.com/theworker02/warpnull.git
cd warpnull
node src/cli.js
node --test
```
